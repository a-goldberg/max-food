# Food Images

Place food image files in this folder.

The sample data in `data/foods.json` expects these filenames:

- `apple.png`
- `carrots.png`
- `oatmeal.png`
- `grilled-chicken.png`
- `cheese-pizza.png`
- `pancakes.png`
- `granola-bar.png`
- `fruit-juice.png`
- `cupcake.png`
- `soda.png`
- `fries.png`
- `candy.png`

Square or wide PNG/JPG images with transparent or simple backgrounds work best. The game will still run before images are added because it shows a simple placeholder when an image file is missing.
